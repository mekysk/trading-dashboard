===================================================================
 ชุดที่ 2 — ไฟล์สำหรับ GitHub Actions (3 ไฟล์)
===================================================================

ชุดนี้ทำให้มี scan.json ซึ่งหน้าเหล่านี้ต้องใช้:
Scanner · Heat Map · Breadth · Thematic Matrix · แผนลงทุน

ต้องวางตามโครงสร้างนี้เป๊ะๆ

  scripts/scan.mjs            <- จาก github-setup\scripts\
  scripts/universe.txt        <- จาก github-setup\scripts\
  .github/workflows/scan.yml  <- จาก github-setup\.github\workflows\

วิธีสร้างโฟลเดอร์ที่ขึ้นต้นด้วยจุด (.github)
เว็บ GitHub ลากโฟลเดอร์แบบนี้เข้าไปตรงๆ ไม่ได้ ให้ทำแบบนี้แทน

  1. ในหน้า repo กด  Add file > Create new file
  2. ช่องชื่อไฟล์ พิมพ์   .github/workflows/scan.yml
     (พอพิมพ์เครื่องหมาย / มันจะสร้างโฟลเดอร์ให้เอง)
  3. เปิดไฟล์ scan.yml ด้วย Notepad คัดลอกทั้งหมดมาวาง
  4. กด Commit changes

ทำแบบเดียวกันกับ scripts/scan.mjs และ scripts/universe.txt

จากนั้นเปิดสิทธิ์ให้ Actions เขียนไฟล์กลับเข้า repo (ลืมไม่ได้)
  Settings > Actions > General > Workflow permissions
  เลือก  Read and write permissions  แล้วกด Save

แล้วลองรันครั้งแรก
  แท็บ Actions > เลือก "สแกนหุ้นรายคืน" > Run workflow
  รอ 3-6 นาที จะมีไฟล์ scan.json โผล่ขึ้นมาใน repo
