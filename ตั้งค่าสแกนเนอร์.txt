วิธีเปิดใช้ Quant Scanner แบบเต็ม (สแกน 467 ตัวทุกคืน)
========================================================

หน้า scanner.html ใช้งานได้ทันทีโดยกดปุ่ม "สแกนจากเบราว์เซอร์"
แต่จะได้แค่ 70 ตัว รอ 30-60 วินาที และเลข RS เทียบกันแค่ใน 70 ตัวนั้น

ถ้าอยากได้ของจริง ให้ตั้ง GitHub Actions ตามนี้ ทำครั้งเดียวจบ


ไฟล์ที่ต้องอัปขึ้น repo (นอกเหนือจากไฟล์หน้าเว็บ)
--------------------------------------------------
วางให้ตรงตามโครงสร้างนี้เป๊ะๆ ไม่งั้นหากันไม่เจอ

   scripts/scan.mjs          <- จากโฟลเดอร์ github-setup/scripts/
   scripts/universe.txt      <- จากโฟลเดอร์ github-setup/scripts/
   .github/workflows/scan.yml <- จากโฟลเดอร์ github-setup/.github/workflows/
   engine.js                 <- อยู่ใน UPLOAD-ME อยู่แล้ว ต้องอยู่ที่ระดับบนสุด


วิธีอัปโฟลเดอร์ที่ขึ้นต้นด้วยจุด (.github)
-------------------------------------------
เว็บ GitHub ลากโฟลเดอร์ชื่อขึ้นต้นด้วยจุดเข้าไปตรงๆ บางทีไม่ได้
ให้ทำแบบนี้แทน

   1. ในหน้า repo กด Add file > Create new file
   2. ช่องชื่อไฟล์ พิมพ์   .github/workflows/scan.yml
      (พอพิมพ์ / มันจะสร้างโฟลเดอร์ให้เอง)
   3. เปิดไฟล์ scan.yml ด้วย Notepad คัดลอกเนื้อหาทั้งหมดมาวาง
   4. กด Commit changes

ทำแบบเดียวกันกับ scripts/scan.mjs และ scripts/universe.txt


เปิดสิทธิ์ให้ Actions เขียนไฟล์กลับเข้า repo
---------------------------------------------
ขั้นนี้ลืมไม่ได้ ไม่งั้นงานจะรันสำเร็จแต่ push ไม่ได้

   Settings > Actions > General
   เลื่อนลงไปหา "Workflow permissions"
   เลือก  Read and write permissions
   กด Save


ทดลองรันครั้งแรก
-----------------
   แท็บ Actions > เลือก "สแกนหุ้นรายคืน" > กด Run workflow
   รอประมาณ 3-6 นาที
   ถ้าสำเร็จ จะมีไฟล์ scan.json โผล่ขึ้นมาใน repo
   กลับมาที่หน้า scanner.html กด "โหลดผลสแกน"


ตารางเวลา
----------
ตั้งไว้ 06:30 UTC = 13:30 เวลาไทย วันอังคารถึงเสาร์
(หลังตลาดสหรัฐฯ ปิดและข้อมูลของคืนนั้นนิ่งแล้ว)
แก้เวลาได้ที่บรรทัด cron ในไฟล์ scan.yml


ถ้างานล้มเหลว
--------------
สคริปต์ตั้งใจให้ "ล้มเหลวดีกว่าเขียนทับด้วยข้อมูลผิด"
มันจะหยุดและไม่แตะไฟล์เดิม เมื่อ

   - ดึงข้อมูลได้น้อยกว่า 70% ของรายชื่อทั้งหมด
   - มีหุ้นที่ข้อมูลครบ 1 ปีน้อยกว่า 50 ตัว

เหตุผล: RS คิดจากการเอาหุ้นมาเรียงเทียบกันเองทั้งชุด
ถ้าชุดไม่ครบ อันดับจะเพี้ยนทั้งกระดาน และคุณจะไม่รู้ตัวเลย
ไฟล์เก่าที่ถูกต้อง ดีกว่าไฟล์ใหม่ที่ผิด

ดูสาเหตุได้ในล็อกของ Actions จะบอกเป็นรายตัวว่าตัวไหนดึงไม่ได้เพราะอะไร


แก้รายชื่อหุ้นที่สแกน
----------------------
แก้ไฟล์ scripts/universe.txt ได้เลย หนึ่งตัวต่อบรรทัดหรือเว้นวรรคก็ได้
บรรทัดขึ้นต้นด้วย # คือหมายเหตุ ไม่ถูกอ่าน

หมายเหตุ: รายชื่อตั้งต้นมาจากหุ้นใหญ่ในสหรัฐฯ ประมาณ 467 ตัว
บางตัวอาจถูกควบรวมหรือถอดออกจากตลาดไปแล้ว พวกนี้จะดึงไม่ได้
และถูกข้ามอัตโนมัติ ดูรายชื่อได้ในล็อก แล้วค่อยลบทิ้งทีหลังก็ได้
